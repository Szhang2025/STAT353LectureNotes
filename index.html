01 Sample Space, Events & Counting ▼
Concept: A sample space (S) lists all possible outcomes. An event is a subset of S. Counting rules (multiplication, permutations, combinations) help count outcomes without listing.

📌 Key Definitions & Notation

  • Sample space (S): The set of all possible outcomes. Example: rolling a die → S = {1,2,3,4,5,6}.
  • Event: A subset of S. Example: A = "roll an even number" = {2,4,6}.
  • Union (A ∪ B): Outcomes in A or B (or both).
  • Intersection (A ∩ B): Outcomes in both A and B.
  • Complement (Aᶜ or A'): Outcomes in S but not in A.
  • Disjoint (mutually exclusive): A ∩ B = ∅, so P(A ∩ B) = 0.
  • Multiplication rule: If a task has k steps with n₁, n₂, …, nₖ choices → n₁ × n₂ × … × nₖ total outcomes.
  • Permutation: P(n,r) = n! / (n−r)! (order matters).
  • Combination: C(n,r) = n! / [r!(n−r)!] (order doesn't matter).
📌 Exercise A bag contains 5 red, 4 blue, and 3 green marbles. Two marbles are drawn without replacement. (a) How many ordered outcomes are in the sample space? (b) How many outcomes are in the event “both marbles are the same color”? (c) How many outcomes are in the event “at least one red”? Express using set notation with the complement.
✅ Detailed solution
  • (a) Sample space: Ordered draws without replacement: first marble 12 choices, second 11 choices → 12 × 11 = 132 ordered outcomes.
  • (b) Same color event: Count ordered outcomes: RR = 5×4 = 20, BB = 4×3 = 12, GG = 3×2 = 6. Total = 20+12+6 = 38.
  • Check with combinations: Unordered total C(12,2)=66. Same color unordered: C(5,2)+C(4,2)+C(3,2)=10+6+3=19. Doubling gives 38 ordered. ✅
  • (c) "At least one red" event: Let R = event that at least one red marble is drawn.
  • The complement Rᶜ = "no red marbles," meaning both draws come from the 7 non-red marbles (4 blue + 3 green).
  • Number of ordered outcomes in Rᶜ: 7 × 6 = 42.
  • Therefore, |R| = 132 − 42 = 90.
  • Set notation: Rᶜ = { (x,y) ∈ S : x ∉ Red and y ∉ Red } and R = S \ Rᶜ.
  • Answer: (a) 132 ordered outcomes. (b) 38 outcomes for “same color”. (c) 90 outcomes for "at least one red"; R = S \ Rᶜ where Rᶜ consists of ordered pairs drawn from the 7 non-red marbles.
⚠️ Correction note: Earlier versions incorrectly wrote Rᶜ = {BB, BG, GB, GG}. This was wrong because those are color labels, not elements of the ordered sample space, and it ignored the multiplicity (counts) of each combination. The complement correctly contains 42 ordered outcomes, not 4.
02 Probability of an Event ▼
Concept: For equally likely outcomes, P(A) = |A| / |S|. Probability is always between 0 and 1, and P(S)=1.
📌 Exercise A fair six-sided die is rolled twice. What is the probability that the sum of the two rolls is 7 or 11?
✅ Detailed solution
  • Sample space: 36 equally likely ordered pairs (1,1) … (6,6).
  • Event sum=7: (1,6),(2,5),(3,4),(4,3),(5,2),(6,1) → 6 outcomes.
  • Event sum=11: (5,6),(6,5) → 2 outcomes. Disjoint from sum=7.
  • Total favorable: 6 + 2 = 8.
  • P(sum=7 or 11) = 8/36 = 2/9 ≈ 0.2222
  • Answer: 2/9.
03 Disjoint & Independent Events ▼
Concept: Disjoint events cannot occur together: P(A∩B)=0. Independent events satisfy P(A∩B)=P(A)P(B). These are different ideas — disjoint events with positive probability are dependent.
📌 Exercise Let A and B be events with P(A)=0.4, P(B)=0.5, and P(A∪B)=0.7. (a) Are A and B disjoint? (b) Are they independent?
✅ Detailed solution
  • (a) Disjoint means P(A∩B)=0. Using inclusion–exclusion: P(A∪B)=P(A)+P(B)−P(A∩B) → 0.7 = 0.4+0.5 − P(A∩B) → P(A∩B)=0.2 ≠ 0. So not disjoint.
  • (b) Independent if P(A∩B)=P(A)P(B). P(A)P(B)=0.4×0.5=0.2, which equals P(A∩B)=0.2. Thus independent.
  • Answer: (a) No, not disjoint. (b) Yes, independent.
04 Total Probability & Bayes' Formula ▼
Concept: Total probability: P(B) = Σ P(Aᵢ)P(B|Aᵢ) over a partition. Bayes' theorem reverses conditioning: P(A|B) = P(A)P(B|A) / P(B).

📌 What is a Partition?

  • A partition of a sample space S is a collection of events A₁, A₂, …, Aₖ that are:
    • Mutually exclusive: Aᵢ ∩ Aⱼ = ∅ for all i ≠ j.
    • Exhaustive: A₁ ∪ A₂ ∪ … ∪ Aₖ = S.
  • In other words, every outcome in S belongs to exactly one Aᵢ.
  • Example: For a die roll, A₁ = {1,2}, A₂ = {3,4}, A₃ = {5,6} form a partition.
📌 Exercise A factory has two machines. Machine A produces 60% of items, Machine B produces 40%. 3% of A’s items are defective, 5% of B’s are defective. An item is chosen at random and found defective. What is the probability it came from Machine A?
✅ Detailed solution
  • Let D = defective. P(A)=0.6, P(B)=0.4, P(D|A)=0.03, P(D|B)=0.05.
  • Total probability: P(D) = P(A)P(D|A)+P(B)P(D|B) = 0.6×0.03 + 0.4×0.05 = 0.018+0.020=0.038.
  • Bayes: P(A|D) = P(A)P(D|A) / P(D) = 0.018 / 0.038 = 18/38 = 9/19 ≈ 0.4737.
  • Answer: 9/19 ≈ 0.474.
05 Discrete Random Variables ▼
Concept: A discrete RV takes countable values with probabilities. E(X)=Σ x·P(x), Var(X)=E(X²)−[E(X)]².

📊 PMF, CDF & Key Distributions

  • PMF (Probability Mass Function): p(x) = P(X = x). Must satisfy: p(x) ≥ 0 and Σ p(x) = 1.
  • CDF (Cumulative Distribution Function): F(x) = P(X ≤ x) = Σ_{k≤x} p(k). It is non-decreasing, right-continuous, F(−∞)=0, F(+∞)=1.
  • Binomial Distribution: X ~ Binomial(n,p) = number of successes in n independent trials.
    P(X = k) = C(n,k) p^k (1−p)^{n−k},   k = 0, 1, …, n
    E(X) = np,   Var(X) = np(1−p)
  • Geometric Distribution: X ~ Geometric(p) = number of trials until first success.
    P(X = k) = (1−p)^{k−1} p,   k = 1, 2, 3, …
    E(X) = 1/p,   Var(X) = (1−p)/p²
  • Poisson Distribution: X ~ Poisson(λ) = number of events in a fixed interval.
    P(X = k) = (λ^k e^{−λ}) / k!,   k = 0, 1, 2, …
    E(X) = λ,   Var(X) = λ
📌 Exercise (a) X ~ Binomial(n=3, p=0.5). Find E(X) and Var(X). (b) Let X ~ Geometric(p=0.2). Find P(X=3) and E(X). (c) Let X ~ Poisson(λ=4). Find P(X=2) and Var(X).
✅ Detailed solution
  • (a) X ~ Binomial(n=3, p=0.5). Probabilities: P(0)=1/8, P(1)=3/8, P(2)=3/8, P(3)=1/8.
  • E(X) = np = 3×0.5 = 1.5. Var(X) = np(1−p) = 3×0.5×0.5 = 0.75.
  • (b) Geometric(p=0.2): P(X=3) = (1−0.2)^{3−1}×0.2 = 0.8²×0.2 = 0.64×0.2 = 0.128. E(X) = 1/p = 1/0.2 = 5.
  • (c) Poisson(λ=4): P(X=2) = (4² e^{−4}) / 2! = (16 × 0.018315) / 2 ≈ 0.1465. Var(X) = λ = 4.
  • Answer: (a) E(X)=1.5, Var(X)=0.75. (b) P(X=3)=0.128, E(X)=5. (c) P(X=2)≈0.1465, Var(X)=4.
06 Continuous Random Variables ▼
Concept: Continuous RVs have a probability density function (PDF). Probabilities are areas under the PDF. For Uniform[a,b], f(x)=1/(b−a) on [a,b].

📈 Exponential, Normal & Z‑score

  • Exponential Distribution: X ~ Exp(λ), λ > 0 (rate).
    PDF: f(x) = λe^{−λx},   x ≥ 0
    CDF: F(x) = 1 − e^{−λx},   x ≥ 0
    Mean: E(X) = 1/λ,   Variance: Var(X) = 1/λ²
  • Normal Distribution: X ~ N(μ, σ²).
    PDF: f(x) = (1/(σ√(2π))) e^{−(x−μ)²/(2σ²)}
    Mean: E(X) = μ,   Variance: Var(X) = σ²
    Empirical Rule (68‑95‑99.7): ~68% within μ±σ, ~95% within μ±2σ, ~99.7% within μ±3σ
  • Z‑score: Standardizes any normal value:
    z = (x − μ) / σ
    Converts to standard normal N(0,1).
📌 Exercise (a) Let X ~ Uniform[2,8]. Find P(X<5), median, mean. (b) Let X ~ Exp(λ=0.5). Find mean, std, P(X>4). (c) Let X ~ N(μ=100, σ=15). Find P(X<115) using z-score and state the empirical rule range for 95%.
✅ Detailed solution
  • (a) Uniform[2,8]: f(x)=1/6. P(X<5) = (5−2)/6 = 0.5. Median = (2+8)/2 = 5. Mean = (2+8)/2 = 5. Var = (8−2)²/12 = 3.
  • (b) Exp(λ=0.5): Mean = 1/λ = 2. Std = 1/λ = 2. P(X>4) = e^{−0.5×4} = e^{−2} ≈ 0.1353.
  • (c) Normal(100,15): z = (115−100)/15 = 1. P(X<115) = P(Z<1) ≈ 0.8413. 95% range: μ ± 2σ = 100 ± 30 → (70, 130).
  • Answer: (a) 0.5, 5, 5. (b) 2, 2, 0.1353. (c) 0.8413, (70,130).

🔗 Connection: Exponential ↔ Poisson

  • Poisson process: Events occur randomly in continuous time at a constant average rate λ.
  • Poisson distribution counts the number of events in a fixed interval: N(t) ~ Poisson(λt).
  • Exponential distribution models the waiting time between consecutive events: if events follow a Poisson process with rate λ, the time between events is Exp(λ).
  • Key relationship: P(T > t) = e^{−λt} = probability of zero events in time t = P(N(t) = 0).
  • Summary: Poisson = counting; Exponential = timing. They are two views of the same underlying process.

⛓️ Application: Blockchain & Hashing

  • Poisson in blockchain: Blocks are mined at roughly constant rate (e.g., Bitcoin ~1 block/10 min). The number of blocks mined in time t follows Poisson(λt).
  • Exponential in blockchain: The time until the next block is found follows Exp(λ). E.g., with λ = 1/600 seconds, the expected wait is 600 s = 10 min.
  • Hashing and proof-of-work: A hash function maps any input to a fixed-size output. Miners repeatedly try random nonces until the hash falls below a target (e.g., starts with many zeros).
  • Each hash attempt is an independent Bernoulli trial with success probability p (e.g., p = 2^{−32} for a difficulty target).
  • The number of attempts until success follows a Geometric distribution with mean 1/p.
  • Probability of finding a block in n attempts: 1 − (1−p)^n.
  • Connection: Geometric → Exponential (in the limit of small p and large n), and Poisson counts rare events in time — tying hashing, mining, and the Poisson process together.
07 Joint Distributions of Two Discrete RVs ▼
Concept: The joint PMF p(x,y) gives probabilities for pairs. Marginal PMFs come from summing over the other variable. Covariance measures linear dependence.

📐 Correlation Coefficient (ρ or r)

  • Correlation: ρ = Cov(X,Y) / (σₓ · σᵧ) for populations; r for samples.
  • Range: −1 ≤ ρ ≤ 1.
  • Interpretation: ρ = 1 → perfect positive linear; ρ = −1 → perfect negative linear; ρ = 0 → no linear relationship.
  • Correlation only measures linear association. ρ = 0 does not mean independence (unless jointly normal).
  • Note on notation: σₓ = population standard deviation of X; σᵧ = population standard deviation of Y.
📌 Exercise Joint PMF: p(0,0)=0.1, p(0,1)=0.2, p(1,0)=0.3, p(1,1)=0.4. Find P(X=1), P(Y=0|X=1), Cov(X,Y), and correlation ρ.
✅ Detailed solution
  • P(X=1): 0.3+0.4=0.7.
  • P(Y=0|X=1): 0.3/0.7 ≈ 0.4286.
  • Marginals: P(X=0)=0.3, P(X=1)=0.7. P(Y=0)=0.4, P(Y=1)=0.6.
  • E(X)=0.7, E(Y)=0.6, E(XY)=0.4.
  • Cov(X,Y): 0.4 − 0.7×0.6 = −0.02.
  • Var(X): E(X²)=0.7, Var=0.7−0.49=0.21. So σₓ = √0.21 ≈ 0.4583.
  • Var(Y): E(Y²)=0.6, Var=0.6−0.36=0.24. So σᵧ = √0.24 ≈ 0.4899.
  • Correlation ρ: −0.02 / (0.4583 × 0.4899) = −0.02 / 0.2245 ≈ −0.089.
  • Answer: P(X=1)=0.7, P(Y=0|X=1)≈0.4286, Cov=−0.02, ρ≈−0.089 (weak negative linear relationship).
08 Descriptive Statistics ▼
Concept: Summary measures: mean, median, variance, standard deviation, quartiles. They describe center, spread, and shape of data.

📊 Percentiles, Plots & R (ggplot2)

  • Percentile: The p-th percentile is the value below which p% of data fall. Median = 50th percentile. Q1 = 25th, Q3 = 75th. IQR = Q3 − Q1.
  • Histogram: Displays distribution of a quantitative variable by binning values. Shows shape, center, spread, outliers.
  • Boxplot: Shows median, Q1, Q3, IQR, and outliers (1.5×IQR rule). Useful for comparing groups.
  • Barplot: Displays counts/frequencies for categorical variables.
  • Piechart: Shows proportions of a whole for categorical data (use with caution).
  • Scatterplot: Displays relationship between two quantitative variables. Look for direction, form, strength, outliers.

📦 R code using ggplot2:

# Load library library(ggplot2) # Histogram ggplot(data, aes(x = variable)) + geom_histogram(binwidth = 5, fill = "steelblue", color = "white") # Boxplot ggplot(data, aes(x = group, y = value)) + geom_boxplot(fill = "lightblue") # Barplot ggplot(data, aes(x = category)) + geom_bar(fill = "coral") # Piechart ggplot(data, aes(x = "", y = count, fill = category)) + geom_bar(stat = "identity") + coord_polar("y") # Scatterplot ggplot(data, aes(x = x_var, y = y_var)) + geom_point() + geom_smooth(method = "lm", se = FALSE)

09 The confidence interval for a Population Proportion ▼
Concept: For a population proportion p, the sample proportion p̂ = X/n is approximately normal for large n.

📐 General Structure of a Confidence Interval

All confidence intervals follow this form:

estimate ± (critical value) × (standard error)
  • Point estimate: Sample statistic (e.g., p̂, x̄, p̂₁−p̂₂).
  • Critical value: z* (normal) or t* (t-distribution) based on confidence level.
  • Standard error: Estimated standard deviation of the statistic.
  • For proportions: SE = √(p̂(1−p̂)/n).
📌 Exercise In a survey of 400 voters, 220 support Candidate A. Construct a 95% confidence interval for the true proportion p.
✅ Detailed solution
  • p̂ = 220/400 = 0.55.
  • Check large-sample condition: n p̂ = 220 ≥ 10, n(1−p̂) = 180 ≥ 10. ✅
  • Standard error: SE = √(0.55×0.45/400) = √0.00061875 ≈ 0.02487.
  • z* for 95% CI = 1.96.
  • Margin of error: 1.96 × 0.02487 ≈ 0.04875.
  • CI: 0.55 ± 0.0488 → (0.5012, 0.5988).
  • Answer: 95% CI for p is approximately (0.501, 0.599).
10 The confidence interval for the Difference of Two Proportions ▼
Concept: Compare p₁ − p₂ using p̂₁ − p̂₂. Standard error: √[p̂₁(1−p̂₁)/n₁ + p̂₂(1−p̂₂)/n₂]. CI uses z*.
📌 Exercise Group 1: 60 successes in 200 trials. Group 2: 40 successes in 180 trials. Find a 90% confidence interval for p₁ − p₂.
✅ Detailed solution
  • p̂₁ = 60/200 = 0.30, p̂₂ = 40/180 ≈ 0.2222.
  • Difference: p̂₁ − p̂₂ = 0.30 − 0.2222 = 0.0778.
  • SE = √[0.30×0.70/200 + 0.2222×0.7778/180] = √[0.00105 + 0.00096] = √0.00201 ≈ 0.04483.
  • z* for 90% CI = 1.645.
  • Margin of error: 1.645 × 0.04483 ≈ 0.0737.
  • CI: 0.0778 ± 0.0737 → (0.0041, 0.1515).
  • Answer: 90% CI for p₁ − p₂ is approximately (0.004, 0.152).
11 The confidence interval for a Population Mean ▼
Concept: When σ is unknown, use t-distribution: x̄ ± t*·(s/√n). Degrees of freedom = n−1.

⚠️ Assumptions for Inference on a Mean

  • Independence: Observations must be independent (random sampling or random assignment).
  • Normality: The population should be approximately normal, OR the sample size should be large (n ≥ 30) so the Central Limit Theorem applies.
  • For small samples (n < 30): Check for normality using a histogram, Q-Q plot, or boxplot. If severely skewed with outliers, consider non-parametric methods.
📌 Exercise A sample of 16 measurements has mean 42.5 and standard deviation 5.2. Construct a 99% confidence interval for the population mean. State the assumptions.
✅ Detailed solution
  • n = 16, df = 15. x̄ = 42.5, s = 5.2.
  • Standard error: SE = s/√n = 5.2/4 = 1.3.
  • t* for 99% CI with df=15: t₀.₉₉₅,₁₅ ≈ 2.947.
  • Margin of error: 2.947 × 1.3 ≈ 3.831.
  • CI: 42.5 ± 3.831 → (38.669, 46.331).
  • Assumptions: (1) Data are independent (random sample). (2) Population is approximately normal. With n=16 (<30), normality should be checked (e.g., histogram or Q-Q plot).
  • Answer: 99% CI for μ is approximately (38.67, 46.33).
12 The confidence interval for the Difference of Two Means ▼
Concept: Two-sample t-interval for μ₁ − μ₂: (x̄₁ − x̄₂) ± t*·√(s₁²/n₁ + s₂²/n₂). Use conservative df or Welch's approximation.

⚠️ Assumptions & Paired Sample Case

  • Independence: The two samples must be independent of each other (unless paired).
  • Normality: Both populations should be approximately normal, or sample sizes large (n₁, n₂ ≥ 30).
  • Paired sample case: When observations are naturally paired (e.g., before/after, twins, matched pairs), analyze the differences dᵢ = x₁ᵢ − x₂ᵢ.
    Use one-sample t-interval on d: d̄ ± t*·(s_d/√n), df = n−1.

13 Foundations of Hypothesis Testing: Null, Alternative & Errors ▼
Concept: A hypothesis test is a formal procedure for deciding between two competing claims about a population parameter using sample data. It answers the question: “Is the observed effect real, or could it have happened by chance?”

🎯 What is a Test of Hypothesis?

A hypothesis test compares what we observe in a sample (a statistic) to what we would expect if a particular claim about the population (a parameter) were true. The logic has three parts:

  • Assume a claim is true (the null hypothesis).
  • Predict what the data should look like under that claim.
  • Measure how far the actual data deviate — if the deviation is too large to be explained by chance, we doubt the claim.

📝 How to Specify H₀ and Hₐ

Every test has two hypotheses:

  • Null hypothesis (H₀): The “status quo” or “no effect” claim. It always contains equality: =, ≤, or ≥. Example: H₀: μ = 100.
  • Alternative hypothesis (Hₐ or H₁): The research claim — what we hope to find evidence for. It contains ≠, <, or >. Example: Hₐ: μ ≠ 100.

Three possible forms (for a mean μ):

TypeH₀HₐMeaning
Two‑tailedμ = μ₀μ ≠ μ₀Any difference from μ₀
Left‑tailedμ ≥ μ₀μ < μ₀Specifically smaller than μ₀
Right‑tailedμ ≤ μ₀μ > μ₀Specifically larger than μ₀

💡 Tip: The alternative hypothesis should reflect the research question. Ask: “What am I trying to prove?” — that goes in Hₐ.

⚠️ The Two Types of Errors

Since we decide based on a sample, we can never be 100% certain. There are two possible mistakes:

  • Type I error (α): Rejecting H₀ when it is actually true. Probability = significance level α. Analogy: convicting an innocent person.
  • Type II error (β): Failing to reject H₀ when Hₐ is actually true. Analogy: letting a guilty person go free.
  • Power (1 − β): The probability of correctly rejecting a false H₀. Higher power is better; typically aim for ≥ 0.80.
  • Trade‑off: For a fixed sample size, decreasing α (making it harder to reject) increases β. The only way to reduce both is to increase the sample size.

🎚️ How to Choose the Significance Level (α)

  • Conventional choices: α = 0.05 is the default in most fields; α = 0.01 for stricter evidence (e.g., medical trials); α = 0.10 for exploratory work.
  • Consider consequences of errors:
    • If a Type I error is costly (e.g., approving a harmful drug), choose a smaller α.
    • If a Type II error is costly (e.g., missing a real disease), choose a larger α or increase power.
  • Balance with power: A smaller α requires a larger sample size to maintain acceptable power.
  • Report the p‑value: Rather than only saying “significant” or “not significant,” report the exact p‑value so readers can judge the strength of evidence.
  • Pre‑register: Choose α before collecting data to avoid p‑hacking.
📌 Exercise For each scenario, state H₀ and Hₐ, identify whether it's one‑ or two‑tailed, and describe what a Type I and Type II error would mean in context.
✅ Detailed solution
  • (a) A coffee shop claims its large latte has 200 mg of caffeine. A customer suspects it's different.
    H₀: μ = 200; Hₐ: μ ≠ 200 (two‑tailed).
    Type I: Concluding the caffeine differs when it's actually 200 mg.

    H₀: μ ≥ 0 (no reduction or increase); Hₐ: μ < 0 (blood pressure decreases). Left‑tailed.
    Type I: Approving a drug that doesn't work.
    Type II: Rejecting a drug that actually works.

    H₀: p ≤ 0.02; Hₐ: p > 0.02. Right‑tailed.
    Type I: Concluding the defect rate is higher when it isn't (unnecessary recall).
    Type II: Missing a genuinely high defect rate (shipping bad products).
Key idea: A hypothesis test weighs evidence against a null claim. H₀ always contains equality; Hₐ reflects the research question. Type I errors (α) are false positives; Type II errors (β) are false negatives. Choose α based on the relative cost of each error and pre‑register it.
14 The General Test Statistic: (statistic − null value) / SE ▼
Concept: Almost every hypothesis test for a mean or proportion uses the same core formula. Standardizing the difference between the observed statistic and the null value by the standard error tells us how many standard errors away the data are from the null hypothesis.

🎯 The General Test Statistic

test statistic = (sample statistic − null value) / standard error

This single formula works for one-sample and two-sample tests of means and proportions.

📐 How the Formula Specializes

Test Statistic Null Value Standard Error Test Stat
1-sample mean (t) x̄ μ₀ s/√n t = (x̄ − μ₀)/(s/√n)
1-sample proportion (z) p̂ p₀ √(p₀(1−p₀)/n) z = (p̂ − p₀)/SE
2-sample mean (t) x̄₁ − x̄₂ 0 √(s₁²/n₁ + s₂²/n₂) t = (x̄₁ − x̄₂)/SE
2-sample proportion (z) p̂₁ − p̂₂ 0 √(p̂(1−p̂)(1/n₁ + 1/n₂)) z = (p̂₁ − p̂₂)/SE

🧭 Interpretation

  • The test statistic measures how many standard errors the observed statistic lies from the null value.
  • Large positive or negative values → the data are far from what H₀ predicts → small p-value → reject H₀.
  • Values close to 0 → the data are consistent with H₀ → large p-value → fail to reject H₀.
  • For a two-sided test, p-value = 2 × P(Z > |z|) or 2 × P(T > |t|).
📌 Exercise A sample of 49 batteries has mean lifetime 98 hours. The company claims the mean is 100 hours. The sample standard deviation is 7 hours. Compute the test statistic for H₀: μ = 100 vs. Hₐ: μ ≠ 100.
✅ Detailed solution
  • Identify the pieces: statistic = x̄ = 98; null value = μ₀ = 100; SE = s/√n = 7/√49 = 7/7 = 1.
  • Apply the general formula: t = (98 − 100) / 1 = −2.0.
  • df = 48. p-value = 2 × P(T > 2.0) ≈ 2 × 0.0255 ≈ 0.051.
  • Since 0.051 > 0.05, fail to reject H₀ at α = 0.05 (borderline).
  • Answer: t = −2.0, p ≈ 0.051, fail to reject H₀.
15 Hypothesis Testing: One Sample (p‑value approach) ▼
Concept: Hypothesis testing decides between a null hypothesis H₀ and an alternative Hₐ using sample data. The p‑value is the probability, assuming H₀ is true, of getting a test statistic at least as extreme as observed. If p‑value ≤ α, reject H₀.

📐 Steps in a Hypothesis Test (p‑value approach)

  1. State H₀ and Hₐ.
  2. Choose significance level α (e.g., 0.05).
  3. Compute the test statistic using (statistic − null value) / SE.
  4. Find the p‑value (area in the tail(s)).
  5. Compare p‑value to α and conclude in context.
📌 Exercise (One-sample t-test for a mean) A coffee shop claims its large latte has 200 mg of caffeine on average. A random sample of 25 lattes has mean 192 mg and standard deviation 12 mg. Test at α = 0.05 whether the true mean differs from 200 mg.
✅ Detailed solution
  • H₀: μ = 200 vs. Hₐ: μ ≠ 200 (two-tailed).
  • Test statistic: t = (x̄ − μ₀) / (s/√n) = (192 − 200) / (12/√25) = −8 / 2.4 = −3.333.
  • df = 24. Find p‑value: P(|T| > 3.333) ≈ 0.0027.
  • Since 0.0027 < 0.05, reject H₀.
  • Conclusion: There is strong evidence the mean caffeine content differs from 200 mg.
📌 Exercise (One-sample z-test for a proportion) A poll claims 50% of residents support a new policy. In a sample of 400 residents, 184 support it. Test at α = 0.05 whether support differs from 50%.
✅ Detailed solution
  • H₀: p = 0.50 vs. Hₐ: p ≠ 0.50.
  • p̂ = 184/400 = 0.46.
  • Test statistic: z = (p̂ − p₀) / √(p₀(1−p₀)/n) = (0.46 − 0.50) / √(0.50×0.50/400) = −0.04 / 0.025 = −1.60.
  • p‑value: 2 × P(Z < −1.60) = 2 × 0.0548 = 0.1096.
  • Since 0.1096 > 0.05, fail to reject H₀.
  • Conclusion: Not enough evidence to say support differs from 50%.
16 Hypothesis Testing: Two Sample (p‑value approach) ▼
Concept: Two-sample tests compare two populations. For means, use the two-sample t-test; for proportions, use the two-sample z-test. The same general formula applies: (statistic − null value) / SE, where the null value is typically 0 (no difference).
📌 Exercise (Two-sample t-test for means) Method A: n₁=12, x̄₁=85, s₁=6. Method B: n₂=15, x̄₂=79, s₂=7. Test at α = 0.05 whether the means differ (use df = 24).
✅ Detailed solution
  • H₀: μ₁ − μ₂ = 0 vs. Hₐ: μ₁ − μ₂ ≠ 0.
  • Statistic: x̄₁ − x̄₂ = 6. Null value = 0.
  • SE = √(s₁²/n₁ + s₂²/n₂) = √(36/12 + 49/15) = √(3 + 3.2667) = √6.2667 ≈ 2.5033.
  • Test statistic: t = (6 − 0) / 2.5033 ≈ 2.397.
  • df = 24. p‑value: 2 × P(T > 2.397) ≈ 2 × 0.0123 = 0.0246.
  • Since 0.0246 < 0.05, reject H₀.
  • Conclusion: There is evidence that the two methods produce different mean results.
📌 Exercise (Two-sample z-test for proportions) Group 1: 60 successes in 200 trials. Group 2: 40 successes in 180 trials. Test at α = 0.05 whether the proportions differ.
✅ Detailed solution
  • H₀: p₁ − p₂ = 0 vs. Hₐ: p₁ − p₂ ≠ 0.
  • p̂₁ = 0.30, p̂₂ ≈ 0.2222. Statistic = 0.0778. Null value = 0.
  • Pooled proportion: p̂ = (60+40)/(200+180) = 100/380 ≈ 0.2632.
  • SE = √[p̂(1−p̂)(1/n₁ + 1/n₂)] = √[0.2632×0.7368×(1/200 + 1/180)] ≈ √[0.1939×0.01056] ≈ √0.002048 ≈ 0.0453.
  • Test statistic: z = (0.0778 − 0) / 0.0453 ≈ 1.718.
  • p‑value: 2 × P(Z > 1.718) ≈ 2 × 0.0429 = 0.0858.
  • Since 0.0858 > 0.05, fail to reject H₀.
  • Conclusion: Not enough evidence to say the proportions differ.
17 Connection: Hypothesis Tests ↔ Confidence Intervals ▼
Concept: A two-sided hypothesis test at significance level α is equivalent to checking whether the null value falls inside a (1−α)×100% confidence interval. Both use the same general formula (statistic − null value) / SE — just rearranged.

🔗 The Duality

  • Decision rule: Reject H₀: μ = μ₀ at level α if and only if μ₀ is not in the (1−α) confidence interval for μ.
  • Why they match: The CI contains all null values μ₀ for which |(x̄ − μ₀)/SE| ≤ critical value. This is exactly the "fail to reject" region of the test.
  • Example: A 95% CI for μ that excludes 200 is equivalent to rejecting H₀: μ = 200 at α = 0.05.
  • The CI gives more information: it shows the range of plausible values, while the test only answers yes/no about a single value.
  • One-sided tests correspond to one-sided confidence bounds (e.g., lower or upper confidence limits).
📌 Exercise In the coffee example (Topic 15), the 95% CI for μ was (187.05, 196.95). Does this agree with the hypothesis test result?
✅ Detailed solution
  • The test rejected H₀: μ = 200 at α = 0.05.
  • The 95% CI is 192 ± 2.064 × (12/√25) = 192 ± 4.954 → (187.05, 196.95).
  • Since 200 is not in the interval, we reject H₀ — exactly matching the test conclusion.
  • Answer: Yes, the CI and the test agree perfectly.
18 Chi-Square Tests: Goodness-of-Fit & Independence ▼
Concept: Chi-square goodness-of-fit tests if observed frequencies match expected. Independence tests if two categorical variables are associated in a contingency table. Statistic: χ² = Σ (O−E)²/E.

🔍 Testing Independence vs. Homogeneity

  • Test of Independence: One sample, two categorical variables. H₀: The two variables are independent.
    Example: Is gender independent of political affiliation?
  • Test of Homogeneity: Multiple populations (groups), one categorical variable. H₀: The distribution of the variable is the same across all groups.
    Example: Is the proportion of defective items the same across three factories?
  • Note: The mechanics (χ² statistic, df = (r−1)(c−1)) are identical. Only the sampling design and interpretation differ.
📌 Exercise (a) A die is rolled 120 times. Observed: 1:15, 2:20, 3:25, 4:18, 5:22, 6:20. Test fairness at α=0.05. (b) In a study of 200 people, test if gender (Male/Female) is independent of smoking status (Smoker/Non-smoker). Observed: Male Smoker=30, Male Non=70, Female Smoker=20, Female Non=80. Test at α=0.05.
✅ Detailed solution
  • (a) Goodness-of-fit: Expected = 20 each. χ² = (15−20)²/20 + 0 + (25−20)²/20 + (18−20)²/20 + (22−20)²/20 + 0 = 1.25+1.25+0.2+0.2 = 2.90. df=5. Critical χ²₀.₀₅,₅ = 11.07. 2.90 < 11.07 → fail to reject. Die is fair.
  • (b) Independence: Table:
    Male: Smoker=30, Non=70, Total=100.
    Female: Smoker=20, Non=80, Total=100.
    Grand total=200. Overall smoker proportion = 50/200 = 0.25.
  • Expected: Male Smoker = 100×0.25 = 25; Male Non = 75; Female Smoker = 25; Female Non = 75.
  • χ² = (30−25)²/25 + (70−75)²/75 + (20−25)²/25 + (80−75)²/75 = 1 + 0.333 + 1 + 0.333 = 2.667.
  • df = (2−1)(2−1) = 1. Critical χ²₀.₀₅,₁ = 3.841. 2.667 < 3.841 → fail to reject.
  • Answer: (a) Die is fair (χ²=2.90, p>0.05). (b) No significant association between gender and smoking (χ²=2.67, p>0.05).
19 One-Way ANOVA ▼
Concept: ANOVA tests equality of means across k groups. F = MS_between / MS_within. If F is large, reject H₀: μ₁=…=μₖ.

⚠️ Assumptions for One-Way ANOVA

  • Independence: Observations within and across groups are independent.
  • Normality: Each group's data are approximately normally distributed.
  • Equal variances (homoscedasticity): The population variance is the same across all groups. Check with Levene's test or residual plots.
📌 Exercise Three groups, each n=5. Group means: 10, 12, 14. Grand mean = 12. SS_between = 40. SS_within = 120. Test at α=0.05. State the assumptions.
✅ Detailed solution
  • k=3 groups, N=15 total. df_between = k−1 = 2, df_within = N−k = 12.
  • MS_between = 40/2 = 20. MS_within = 120/12 = 10.
  • F = 20/10 = 2.0.
  • Critical F₀.₀₅,₂,₁₂ = 3.89. Since 2.0 < 3.89, fail to reject H₀.
  • Assumptions: (1) Independent samples. (2) Each group approximately normal. (3) Equal variances across groups.
  • Answer: No significant difference among group means at α=0.05 (F=2.0, p>0.05).
20 Simple & Multiple Regression ▼
Concept: Simple linear regression fits ŷ = b₀ + b₁x. Multiple regression extends to ŷ = b₀ + b₁x₁ + … + bₖxₖ. R² measures proportion of variance explained.

📈 Interpretation of Coefficients & R-squared

  • Intercept (b₀): Predicted value of y when all predictors are 0. Often not practically meaningful if 0 is outside data range.
  • Slope (b₁): For a one-unit increase in x, y changes by b₁ units on average, holding other variables constant.
  • Multiple regression coefficients (bⱼ): The change in y for a one-unit increase in xⱼ, holding all other predictors fixed.
  • R² (coefficient of determination): Proportion of total variation in y explained by the model. Range: 0 to 1.
    Example: R² = 0.85 → 85% of the variability in y is explained by the predictors.
  • Adjusted R²: Penalizes for adding unnecessary predictors. Use when comparing models with different numbers of predictors.
📌 Exercise For data (x,y): (1,2), (2,4), (3,5), (4,7), (5,8). Find the least-squares line ŷ = b₀ + b₁x, predict y when x=6, and interpret b₁. If R²=0.98, interpret it.
✅ Detailed solution
  • n=5. Σx=15, Σy=26, Σx²=55, Σxy=88. Mean x̄=3, ȳ=5.2.
  • Slope b₁ = (88 − 5·3·5.2) / (55 − 5·9) = (88−78)/(55−45) = 10/10 = 1.
  • Intercept b₀ = 5.2 − 1×3 = 2.2.
  • Line: ŷ = 2.2 + 1.0 x. When x=6: ŷ = 2.2 + 6 = 8.2.
  • Interpretation of b₁: For each additional unit increase in x, y increases by 1.0 unit on average.
  • R² = 0.98: 98% of the variation in y is explained by the linear relationship with x. The model fits very well.
  • Answer: ŷ = 2.2 + 1.0x; predicted y at x=6 is 8.2; b₁=1.0; R²=0.98 means excellent fit.
21 Introduction to Data Mining ▼
Concept: Data mining extracts patterns from large datasets. A core task is predictive modeling, where we split data into training and test sets, fit a model on training data, and evaluate its predictive performance on unseen test data.

🔬 Regression in Data Mining: Training/Test Split & Performance Metrics

  • Training/Test Split: Randomly divide data into:
    • Training set (e.g., 70–80%): Used to fit the model (estimate coefficients).
    • Test set (e.g., 20–30%): Used to evaluate how well the model predicts new, unseen data.
  • Prediction R‑squared (R²_pred): Measures the proportion of variance in the test set explained by the model.
    R²_pred = 1 − [ Σ(yᵢ − ŷᵢ)² / Σ(yᵢ − ȳ)² ]
  • RMSE (Root Mean Squared Error): Measures average prediction error in the original units.
    RMSE = √[ (1/n) Σ(yᵢ − ŷᵢ)² ]
  • Interpretation: Higher R²_pred (closer to 1) and lower RMSE indicate better predictive performance. Comparing training vs. test metrics helps detect overfitting.
📌 Exercise A dataset of 100 observations is split into 70 training and 30 test observations. A multiple regression model is fit on the training set. On the test set, the sum of squared errors (SSE) is 150, and the total sum of squares (SST) is 600. (a) Compute R²_pred for the test set. (b) Compute RMSE if the test set has n=30. (c) Interpret these values.
✅ Detailed solution
  • (a) R²_pred: R²_pred = 1 − SSE/SST = 1 − 150/600 = 1 − 0.25 = 0.75.
  • (b) RMSE: RMSE = √(SSE/n) = √(150/30) = √5 ≈ 2.236.
  • (c) Interpretation: R²_pred = 0.75 → model explains 75% of test variance (good). RMSE ≈ 2.24 → average prediction error. Compare with training metrics to check for overfitting.
  • Answer: (a) R²_pred = 0.75. (b) RMSE ≈ 2.24. (c) Good predictive performance.
22 Control Charts (x̄, R, p) ▼
Concept: Control charts monitor process stability. x̄ chart tracks mean, R chart tracks variability, p chart tracks proportion defective. Points outside control limits signal special causes.

📊 p‑Chart Example

A p-chart monitors the proportion of defective items in samples of size n.

  • Center line: p̄ = total defectives / total inspected.
  • Standard error: SE = √(p̄(1−p̄)/n).
  • Control limits: p̄ ± 3·SE.
  • Example: 20 samples of n=100. Total defectives = 300. p̄ = 300/2000 = 0.15.
  • SE = √(0.15×0.85/100) = √0.001275 ≈ 0.0357.
  • UCL = 0.15 + 3×0.0357 = 0.2571. LCL = 0.15 − 3×0.0357 = 0.0429 (or 0 if negative).
📌 Exercise An x̄ chart uses samples of size n=5. Grand mean x̄̄ = 50, average range R̄ = 4.2. Constants: A₂=0.577, D₃=0, D₄=2.114. (a) Find control limits for x̄ and R charts. (b) For a p-chart with n=100, total defectives=300 in 20 samples, find the control limits.
✅ Detailed solution
  • (a) x̄ chart: UCL = 50 + 0.577×4.2 = 52.42. LCL = 50 − 2.42 = 47.58.
  • R chart: UCL = 2.114×4.2 = 8.88. LCL = 0×4.2 = 0.
  • (b) p-chart: p̄ = 300/(20×100) = 0.15. SE = √(0.15×0.85/100) ≈ 0.0357.
  • UCL = 0.15 + 3×0.0357 = 0.2571. LCL = 0.15 − 3×0.0357 = 0.0429.
  • Answer: (a) x̄: (47.58, 52.42); R: (0, 8.88). (b) p-chart: (0.043, 0.257).
23 Applications: Gacha Probability & LLMs ▼
Concept: Probability and statistics power modern applications — from gacha game mechanics to the probabilistic foundations of large language models (LLMs).

🎮 Gacha Probability: Wuthering Waves

  • Base rate: Each pull has approximately p = 0.8% = 0.008 chance of a 5★ character.
  • Hard pity: Guaranteed 5★ at 80 pulls if none obtained earlier.
  • Soft pity: Rate increases starting around pull 65.
  • 50/50 system: First 5★ has a 50% chance of being featured; if lost, next is guaranteed featured.
  • Let X = pulls until first 5★. If rate were constant at p = 0.008, then X ~ Geometric(p).
  • Geometric CDF: P(X ≤ n) = 1 − (1−p)ⁿ. For n = 10: 1 − (0.992)¹⁰ ≈ 0.0771 → ~7.71% chance within 10 pulls.
  • Expected pulls (without pity): E(X) = 1/p = 125 — which is why pity systems exist!
  • P(X > 60) = (0.992)⁶⁰ ≈ 0.6176 → ~61.8% chance of needing more than 60 pulls without pity.
  • 50/50 outcome: First 5★ has 50% chance featured; if lost, next is 100% featured. So within 2 five-stars, you're guaranteed the featured character.

🧠 Probability in Large Language Models (LLMs)

  • Autoregressive modeling: An LLM defines P(token_t | token_1, …, token_{t−1}) — the probability of each possible next token given the context.
  • Softmax output: Converts logits to probabilities:
    P(token_i) = e^{z_i} / Σ_j e^{z_j}
  • Cross-entropy loss: Training minimizes L = −(1/N) Σ log P(correct token) — the same principle as maximum likelihood estimation.
  • Sampling strategies:
    • Greedy: Pick argmax.
    • Temperature: Divide logits by T. T→0 = greedy; T→∞ = uniform.
    • Top‑k: Sample only from k highest-probability tokens.
    • Top‑p (nucleus): Sample from smallest set whose cumulative probability exceeds p.
  • Perplexity: exp(−(1/N) Σ log P(token_i)) — lower is better.
  • Uncertainty & hallucination: High entropy in the distribution → low-probability, potentially incorrect outputs.
📌 Exercise Suppose an LLM outputs the following logits for the next token: z = [2.0, 1.0, 0.5, 0.0] for tokens {A, B, C, D}. (a) Compute the softmax probabilities. (b) What is the perplexity if the correct token is A? (c) With temperature T = 0.5, recompute the probabilities.
✅ Detailed solution
  • (a) Softmax: e^{2.0} ≈ 7.389, e^{1.0} ≈ 2.718, e^{0.5} ≈ 1.649, e^{0.0} = 1.0.
  • Sum = 7.389 + 2.718 + 1.649 + 1.0 = 12.756.
  • P(A) ≈ 0.5793, P(B) ≈ 0.2131, P(C) ≈ 0.1293, P(D) ≈ 0.0784.
  • (b) Correct token A → cross-entropy = −ln(0.5793) ≈ 0.546. Perplexity = e^{0.546} ≈ 1.726.
  • (c) With T = 0.5: z' = [4.0, 2.0, 1.0, 0.0]. Sum ≈ 65.707.
  • P(A) ≈ 0.831, P(B) ≈ 0.112, P(C) ≈ 0.041, P(D) ≈ 0.015.
  • Lower temperature → sharper, more confident distribution.
  • Answer: (a) [0.579, 0.213, 0.129, 0.078]. (b) Perplexity ≈ 1.73. (c) Sharper distribution: [0.831, 0.112, 0.041, 0.015].
Key idea: The same probability concepts — Geometric, Poisson, Exponential, conditional probability — power gacha mechanics, blockchain hashing, and the softmax/temperature/perplexity pipeline behind modern AI. Master the foundations, and you can reason about any of them.
